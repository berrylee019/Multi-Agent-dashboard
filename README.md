# 🔮 Multi-Agent Central Operating System

이 프로젝트는 다양한 AI SaaS 서비스를 통합 관리하고, 멀티 에이전트 협업을 통해 마케팅 콘텐츠 생성부터 워드프레스 발행까지 한 번에 해결하는 **1인 기업 자동화 대시보드**입니다.

## 🚀 주요 기능
- **동적 서비스 등록**: 새로운 스트림릿(Streamlit) AI 서비스를 코드 수정 없이 대시보드에서 즉시 등록 가능합니다.
- **멀티 에이전트 파이프라인**: 기획, 카피라이팅, 편집 에이전트가 순차적으로 협업하여 최적의 홍보 콘텐츠를 생성합니다.
- **워드프레스 100% 연동**: 생성된 HTML 콘텐츠를 워드프레스 REST API를 통해 클릭 한 번으로 즉시 발행하거나 임시저장합니다.
- **실시간 미리보기**: 발행 전 블로그에 어떻게 보일지 실시간으로 레이아웃을 확인합니다.

## 🛠️ 기술 스택
- **Framework**: Streamlit
- **Language**: Python
- **API**: WordPress REST API
- **AI Logic**: Multi-agent Workflow (Planning -> Writing -> Reviewing)
